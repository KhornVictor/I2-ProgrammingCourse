# References — learn C / C++ by yourself

A list of free websites, YouTube channels and books to continue the course
alone, at home.

> **You do not need all of them.** Pick **one website** and **one YouTube
> channel**, and finish them. Jumping from one resource to another is the most
> common way to learn nothing.

---

## 1. Websites — learn step by step

| Site | Language | Why |
|---|---|---|
| [Programiz](https://www.programiz.com/c-programming) | [C](https://www.programiz.com/c-programming) · [C++](https://www.programiz.com/cpp-programming) | Short lessons, clear examples, an online compiler on the same page. **Best place to start.** |
| [W3Schools](https://www.w3schools.com/c/) | [C](https://www.w3schools.com/c/) · [C++](https://www.w3schools.com/cpp/) | Very simple, "Try it yourself" button on every example |
| [GeeksforGeeks](https://www.geeksforgeeks.org/c-programming-language/) | [C](https://www.geeksforgeeks.org/c-programming-language/) · [C++](https://www.geeksforgeeks.org/c-plus-plus/) | Huge number of articles on data structures and algorithms — search here when you are stuck on an exercise |
| [TutorialsPoint](https://www.tutorialspoint.com/cprogramming/) | [C](https://www.tutorialspoint.com/cprogramming/) · [C++](https://www.tutorialspoint.com/cplusplus/) | Complete and well organised, close to the style of our slides |
| [LearnCpp.com](https://www.learncpp.com/) | C++ | The most complete free C++ course on the internet. Long, serious, and it explains **why**, not only how. Go there after this course. |

## 2. Reference — look up a function

Not for learning: for checking the exact behaviour of `strcpy`, `getline`,
`ifstream`, etc.

- [cppreference.com](https://en.cppreference.com/) — the official-quality reference for C and C++ (advanced, but always correct)
- [cplusplus.com](https://cplusplus.com/reference/) — easier to read for a beginner

## 3. See the data structures move  ⭐

This is the most useful category for **our** course. A linked list, a tree or a
sorting algorithm is much easier to understand when you **watch** it.

| Site | What it does |
|---|---|
| [VisuAlgo](https://visualgo.net/en) | Animates linked lists, stacks, queues, hash tables, BST, all the sorting algorithms. Made for exactly this course. |
| [USFCA Data Structure Visualizations](https://www.cs.usfca.edu/~galles/visualization/Algorithms.html) | The same idea, simpler and faster to use |
| [Python Tutor (C / C++ mode)](https://pythontutor.com/c.html) | Paste **your own** code, run it line by line and **see the pointers and the memory boxes**. Perfect for `L4-Pointer.cpp` and `L5-LinkedList.cpp`. |
| [Compiler Explorer (godbolt)](https://godbolt.org/) | Shows what the compiler really produces. Curiosity only — not needed for the exam. |

## 4. Online compilers — no installation

Useful on a phone, on a borrowed computer, or when the school computer has no
Code::Blocks.

- [OnlineGDB](https://www.onlinegdb.com/) — supports C **and** C++, and it has a **debugger** (step by step)
- [Programiz online compiler](https://www.programiz.com/cpp-programming/online-compiler/)
- [Replit](https://replit.com/) — needs an account, but saves your projects

## 7. Practise — the only way to really learn

| Site | Level | For what |
|---|---|---|
| [HackerRank](https://www.hackerrank.com/domains/c) | beginner → medium | Has a real **C** track and a **C++** track, with exercises sorted by topic (loops, arrays, structs…) |
| [Exercism](https://exercism.org/tracks/cpp) | beginner → medium | Free exercises, and a human mentor reads your code |
| [Codewars](https://www.codewars.com/) | beginner → hard | Small puzzles, you compare your solution with the others |
| [LeetCode](https://leetcode.com/) | medium → hard | Linked lists, trees, hash tables — the exercises of our Part 2, but harder. Also what companies ask in interviews. |
| [Project Euler](https://projecteuler.net/) | maths | Problems with loops and numbers, if you like mathematics |
| [Codeforces](https://codeforces.com/) | hard | Programming competitions |

**Start with HackerRank**, section by section, following the order of our
course. Do not start with LeetCode.

## 10. How to actually learn (please read this part)

1. **Watching a video is not learning.** Stop the video, close it, and write
   the program yourself. If you cannot, you did not understand it — watch again.
2. **Type the code, never copy-paste it.** Your fingers must learn the syntax
   too. And every typing mistake teaches you a compiler error message.
3. **One hour of exercises beats five hours of videos.**
4. **Read the error message.** It gives the file, the line and the reason. Most
   students look at the code instead of reading the message.
5. **Draw before you code** — especially the linked list, the stack, the queue
   and the tree. Arrows on paper, then code.
6. **Explain it to a classmate.** If you cannot explain it, you do not know it.
7. **Do not give up on a bug too fast.** Twenty minutes of struggle teaches
   more than the answer given immediately.
